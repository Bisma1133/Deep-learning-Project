## 🏗️ System Specifications

### What the System Does

**OMC** is a comprehensive business management platform that provides:

1. **Company Formation** - Incorporate businesses
2. **Tax Registration** - VAT & Corporate Tax
3. **Tax Filing** - Submit VAT/CT returns
4. **Bookkeeping** - Transactions, invoices, reports
5. **Social Media** - Multi-platform management
6. **Telephony** - Calls and SMS
7. **Unified Messaging** - WhatsApp, Facebook, Instagram
8. **Payments** - Stripe integration, subscriptions
9. **Support** - Tickets, FAQ, knowledge base
10. **Admin Tools** - Client management

### Stakeholders

**3 User Types**:
1. **Super Admin** - System owner, full access
2. **Admin** - Consultant, manages clients
3. **Client** - Business owner, uses services

### Technology Stack

**Frontend**:
- Next.js 14 + React 18 + TypeScript
- Tailwind CSS + Shadcn/ui
- React Query + Zustand

**Backend**:
- Node.js 18 + Express + TypeScript
- PostgreSQL 14 + Sequelize
- Redis 7 + JWT Auth

**Integrations**:
- ZOHO Books, QuickBooks (accounting)
- WhatsApp, Facebook, Instagram (messaging)
- Stripe (payments)
- Twilio (telephony)
- Google OAuth (authentication)
